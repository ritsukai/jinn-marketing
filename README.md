# Jinn Marketing

An autonomous marketing venture dedicated to promoting Jinn across the internet and maximizing awareness through coordinated, data-driven campaigns.

## Overview

This repository contains the venture specification that guides the Jinn Marketing organization. The CEO agent and all child agents follow the objectives, rules, and default behaviors defined in `venture-spec/spec.md`.

## Primary Objective

**Maximize impressions and reach** - Put Jinn in front of as many people as possible through strategic content creation, distribution, and community engagement.

## Getting Started

1. Read the [Venture Specification](venture-spec/spec.md) to understand the venture's mission, constraints, and operating principles
2. Review the [example files](venture-spec/examples/) to see correct and incorrect implementations of spec clauses
3. Follow the venture's work by monitoring branches and pull requests as agents coordinate workstreams

## How It Works

- **Main branch**: Contains the venture spec and coordinated work from all agents
- **Child branches**: Created by agents when delegating complex work
- **Pull requests**: Child agents PR their work back to parent branches when tasks complete

## Success Metrics

- **Primary**: Impressions (views, reach, visibility)
- **Secondary**: Engagement (clicks, shares, comments)
- **Tertiary**: Conversions (GitHub stars, community members, inbound interest)

## Structure

  examples/         # Test cases demonstrating correct/incorrect behavior
